Урок 1 - Знакомство с HTML

Заголовок первого уровня может быть только один на всей странице. Заголовки другх уровней могут быть в большом количестве. Всего 6 уровней заголовков.

Знакомство с EMMET и его сниппетами

EMMET - это плагин для редактора кода, который позволяет быстро создавать HTML-структуру с помощью сокращений. Например, если вы хотите создать структуру из 3 абзацев, вы можете написать "p*3" и нажать Tab, и EMMET автоматически создаст 3 абзаца для вас.

Математика и операторы EMMET

  • ТЕГ - дает возможность создать тег который выхотите
  • ТЕГ{Текстовое содержимое} - позволяет создать тег с текстовым содержимым
  • ТЕГ*ЧИСЛО - позволяет создать несколько одинаковых тегов
  • ТЕГ>ТЕГ - позволяет создать вложенные теги
  • ТЕГ+ТЕГ - позволяет создать соседние теги
  • ТЕГ^ТЕГ - позволяет подняться на уровень вверх
  • ТЕГ>ТЕГ*3 - позволяет создать вложенные теги с повторением
