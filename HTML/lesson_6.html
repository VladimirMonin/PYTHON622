Типы input

  • text - однострочное текстовое поле
  • password - поле для ввода пароля
  • email - поле для ввода email
  • number - поле для ввода чисел
  • date | time | datetime - поле для ввода даты
  • checkbox - флажок многие из многих
  • radio - переключатель один из многих
  • submit - кнопка отправки формы
  • reset - кнопка сброса формы
  • tel - поле для ввода телефонного номера
  • color - поле для выбора цвета
  • file - поле для загрузки файлов
  • range - ползунок для выбора значения из диапазона
