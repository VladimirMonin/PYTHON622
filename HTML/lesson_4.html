Шрифты и box-model

Знакомство с шрифтами

Шрифт - это набор символов, который используется для отображения текста на веб-странице. В CSS мы можем задавать шрифты с помощью свойства font-family. Например: 

        
        p {
            font-family: Arial, sans-serif;
        }

Глобально, есть 5 основных семейств шрифтов:

  • Serif - шрифты с засечками. Используются для печатных изданий.
  • Sans-serif - шрифты без засечек. Используются для веб-дизайна.
  • Monospace - моноширинные шрифты. Используются для кода.
  • Cursive - рукописные шрифты. Используются для декоративного текста.
  • Fantasy - декоративные шрифты. Используются для заголовков и плакатов.
